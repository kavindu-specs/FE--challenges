# 🎯 Frontend Challenges 

This repository contains a collection of frontend challenges completed using only **HTML**, **CSS**, and **vanilla JavaScript**. These projects are built to strengthen my core web development skills by focusing on clean layouts, responsive design, and interactivity — without relying on frontend frameworks.

All challenges were sourced from [Frontend Mentor](https://www.frontendmentor.io/), a great platform for practicing real-world frontend development problems.

---

## 🚀 Purpose

To master the fundamentals of frontend development through hands-on experience by building pixel-perfect, responsive UI components and pages.

---

## 🛠️ Technologies Used

- **HTML5** — Semantic and accessible structure  
- **CSS3** — Styling and layout (Flexbox, Grid, Media Queries)  
- **JavaScript (ES6+)** — Interactivity and DOM manipulation  
- No frameworks or libraries used — 100% vanilla code!

---

## 📁 Projects

Each folder contains:

- Source code (`index.html`, `style.css`, `script.js`)  
- Assets (images/fonts if required)  
- User Interface Designs
